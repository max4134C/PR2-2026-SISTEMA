# PR2 2026: Gestión de recursos virtuales en Proxmox VE

Proyecto académico sobre gestión de recursos virtuales en Proxmox VE y conectividad remota mediante SSH. El alcance y las tecnologías de implementación se definirán durante el semestre.

## Estructura del repositorio

- docs/: informe, presentación, planificación y documentación técnica.
- src/: código fuente del sistema.
- tests/: pruebas y datos de prueba no sensibles.
- infra/: configuración reproducible de infraestructura.
- scripts/: automatizaciones y utilidades.
- assets/: recursos visuales de la documentación.

La estructura de código se ajustará cuando se definan la arquitectura y las tecnologías.
