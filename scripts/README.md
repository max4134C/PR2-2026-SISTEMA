# Scripts

Guardar aquí automatizaciones auxiliares para construir, probar y validar el prototipo académico y las tareas del laboratorio propio. Cada script debe explicar propósito, dependencias, parámetros, salida y efectos secundarios antes de ejecutarse.

No incluir credenciales ni comandos dirigidos a sistemas de BoA. Probar cambios en el entorno local o laboratorio autorizado y mantener secretos fuera del repositorio.
