# Documentación

## Material actual

- Informe técnico: archivo PDF disponible en la raíz del repositorio.
- Presentación inicial: archivo PPTX disponible en la raíz.
- Planificación: agregar aquí el Gantt cuando el equipo lo incorpore; actualmente no está en el repositorio.

## Organización recomendada

- informe/: informe final y, si es posible, sus fuentes editables.
- presentaciones/: presentaciones y materiales de exposición.
- planificacion/: Gantt, hitos y planificación del semestre.
- requisitos/: alcance, requisitos y criterios de aceptación.
- diseno/: arquitectura, decisiones técnicas y diagramas.
- actas/: acuerdos que generen decisiones o tareas.

Mantengan aquí la documentación que ayude a entender, construir, probar u operar el sistema. Registren tareas y decisiones pendientes como Issues.
