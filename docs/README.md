# Documentación del proyecto

La documentación describe un prototipo académico de plataforma web de boletos y una propuesta hiperconvergente con Proxmox VE. BoA es el contexto del caso de estudio; este repositorio no es oficial ni autoriza acceso a sistemas o datos reales.

## Material actual

- Informe técnico protegido: en la raíz. No modificar ni reemplazar.
- Presentación inicial: en la raíz.
- Gantt: aún no está en el repositorio; agregarlo en planificacion/.

## Organización

- requisitos/: alcance, usuarios ficticios e historias verificables.
- arquitectura/: componentes de la plataforma, topología del laboratorio y decisiones.
- planificacion/: Gantt, hitos y entregables del semestre.
- operacion/: despliegue, observabilidad, respaldo y recuperación cuando se definan.
- actas/: acuerdos del equipo con impacto en alcance o decisiones.

Registren el trabajo en Issues y enlacen las decisiones documentadas a sus Issues o Pull Requests.
