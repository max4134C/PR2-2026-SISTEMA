# Documentación del proyecto

Este repositorio describe un prototipo académico de plataforma web de boletos y una propuesta hiperconvergente con Proxmox VE. BoA es únicamente el contexto del caso de estudio: el proyecto no es oficial y no autoriza acceso a sistemas o datos reales. Usar exclusivamente datos sintéticos.

## Material existente

- Informe técnico protegido: [Informe Tecnico Proxmox BoA-UNIFRANZ.pdf](../Informe%20Tecnico%20Proxmox%20BoA-UNIFRANZ.pdf), en la raíz y sin modificaciones.
- Presentación inicial: [Gestión de Recursos Virtuales en Proxmox VE y Conectividad Remota por SSH.pptx](../Gesti%C3%B3n%20de%20Recursos%20Virtuales%20en%20Proxmox%20VE%20y%20Conectividad%20Remota%20por%20SSH.pptx), en la raíz.
- [Plantilla Gantt del semestre](planificacion/GANTT.md): completar fechas, responsables y dependencias con acuerdos del equipo.

## Documentos de trabajo

- [Requisitos y límites del prototipo](requisitos/README.md): funciones previstas, usuarios ficticios y exclusiones.
- [Arquitectura propuesta](arquitectura/README.md): capas lógicas, validación del laboratorio y decisiones pendientes.
- [Planificación](planificacion/README.md): seguimiento de hitos y enlace con el tablero.
- `src/README.md`: guía para el futuro código fuente.
- `infra/README.md`: inventario y configuración segura del laboratorio Proxmox VE.
- `tests/README.md`: alcance de las pruebas con datos sintéticos.
- `scripts/README.md`: pautas de automatización auxiliar.
