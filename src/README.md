# Código fuente

Aquí se implementará el prototipo académico de venta de boletos: consulta de vuelos ficticios, reserva simulada y consulta de reserva. Separar presentación, lógica de aplicación y persistencia según la arquitectura aprobada.

No elegir frameworks antes de un acuerdo del equipo. Usar exclusivamente datos sintéticos; no conectar con servicios de BoA, pagos, emisión real ni datos personales. Mantener la instalación, ejecución y configuración de ejemplo documentadas en el README principal.
