# Pruebas

Incluir pruebas de búsqueda y selección de vuelos ficticios, reserva de demostración y consulta mediante código simulado. Añadir pruebas de integración y despliegue cuando exista una implementación.

Las pruebas de respaldo, restauración y resiliencia deben limitarse a capacidades verificadas del laboratorio y ejecutarse solo en entornos autorizados. Usar exclusivamente datos sintéticos: nada de datos personales, pagos reales, endpoints o credenciales de BoA. Documentar comandos y resultados reproducibles en la guía de desarrollo.
